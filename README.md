# Zomato Data Analysis Project

## 📌 Project Overview
This project is based on Zomato dataset analysis using Python.  
It helps to understand restaurant trends, ratings, and customer preferences.

## 📊 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📈 Key Analysis
- Top rated restaurants
- City-wise restaurant distribution
- Cost analysis
- Ratings distribution

## 🚀 How to Run
1. Open Jupyter Notebook 
2. Run the  app.py file
3. Install required libraries if needed
